## 1. 五分钟上手

```bash
export NVM_DIR="$HOME/.config/nvm" && . "$NVM_DIR/nvm.sh"   # pnpm 需要（AGENTS.md 有说明）
pnpm install                        # 必须 pnpm ≥12.18（packageManager 强制）
pnpm tauri dev                      # 完整桌面应用（需要 Rust 工具链）
pnpm dev                            # 仅浏览器（Tauri API 全 mock，快速调 UI）
export PATH="$HOME/.cargo/bin:$PATH"   # cargo 若不在 PATH
```

## 4. 陷阱清单（每个都是真实踩过的）

1. **invoke 的命令名必须在 `lib.rs` 注册**——定义了 `#[tauri::command]` 不够。P0-1 就是这么产生的（`startup_args.rs` 有实现、有 `#[allow(dead_code)]`、就是没注册）。
2. **`.catch` 吞错**：`main.ts` 的 startup args 调用失败完全无感。新 invoke 调用禁止静默 catch。
3. **legacy 路径已删除（R2.1）**——`execute_ffmpeg_command` / `stop_convert` 与无前缀 `progress/finish/error` 事件均已移除；所有 FFmpeg 事件为 `ffmpeg-*` 前缀 + taskId，契约见 `utils/ffmpegEvents.ts`，`legacyPath.test.ts` 防止回流。
4. **`TaskProgress` 的 time/bitrate/speed/size 实际是 string**——别当 number 用（Rust `ProgressInfo` 为准）。
5. **参数面板 watch 只盯 preset id**——深层替换 preset 对象（id 不变）UI 不会更新。
6. **Windows 路径**：自己写的 `split('/')` 都会翻车；用 `split(/[\\/]/)` 或 pathe。
7. **`maxConcurrent` 只在 `tryStartNext` 生效**——直接循环 `startTask` 会绕过它（P0-3）。
8. **pnpm/cargo 在非交互 shell 不在 PATH**——脚本里显式 source nvm、加 `~/.cargo/bin`。
9. **版本有四处**：package.json / Cargo.toml / tauri.conf.json / git tag。Home 页已改读 `__APP_VERSION__`（R0-1），不再硬编码；改版本用 `bump-version.mjs` 同步前三处，tag 手动。
10. **预设时间字段是 ISO 字符串不是 Date**（R2.4）；Rust 返回的 `serde_json::Value` 必须过 `normalizePreset` 才能进 store，旧预设无 `schemaVersion` 时由前端软升级。
11. **`release-all.sh` 的 REPO_DIR 指向父目录**——当前布局下别直接跑（质量保障 §3.1-1）。
12. **独立参数面板窗口会再跑一遍 `main.ts`**（`WebviewUrl::App` 加载同一 index.html），有第二份 Pinia 实例；任何全局副作用（写盘、恢复队列、注册全局监听）都要先判断窗口 label，否则两窗口互相覆盖（R2.5）。`@tauri-store/pinia` 插件虽注册但 `autoStart=false`、无 store 启用，不等于已有持久化。

## 5. 开发流程（沿用 `.agents/skills/` 的既有流程）

```
设计 → 测试先行(红) → 实现(绿) → 验证(质量保障门禁) → 文档同步
```

- 功能开发前：读《重构路线图》确认该事项所处阶段与方案编号，别游离于路线图之外做决定。
- 修复类工作：对照审计报告的编号（P0-1 等），修完把审计报告中的证据等级从 [推断] 升级为 [已验证] 或直接移入"已修复"。
- **文档同步是 PR 的一部分**：改架构改《架构与数据流》；改发布改《质量保障与发布》；改 UI 改《UI-UX重设计规范》对应节。
